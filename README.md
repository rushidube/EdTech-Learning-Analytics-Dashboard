# EdTech Learning Analytics — Student Dropout & Early Risk Analysis

An end-to-end data analytics project analyzing student engagement, academic performance, demographics, course characteristics, and dropout patterns using the Open University Learning Analytics Dataset (OULAD).

The project combines Python-based data preparation and exploratory analysis, PostgreSQL analytics, Power BI dashboarding, and machine learning-based early-warning analysis.

## 📌 Project Overview

Student dropout is a major challenge in online education. Identifying behavioral and academic patterns associated with withdrawal can help educational institutions understand where students are at greater risk and where intervention may be required.

This project analyzes student-level learning activity and academic data to:

- Analyze overall student outcomes
- Identify dropout patterns across courses and presentations
- Examine the relationship between engagement and academic performance
- Analyze dropout patterns across demographic groups
- Identify early engagement indicators associated with dropout
- Build an interactive Power BI analytics dashboard
- Develop an early-warning machine learning analysis using behavioral and academic features
